# Reference Projects / Ideas to Borrow

Use projects as references, not as a reason to couple the product to their internals.

- **WrightTest:** recorder + visual test management + Playwright export concept.
- **QA Studio:** visual step/action UX and assertion authoring.
- **Playwright Live Recorder:** in-browser recording/locator interaction ideas.
- **TestBlocks:** JSON intermediate representation and extensible action catalog.
- **SuiSui / playwright-bdd:** reusable business-readable steps.
- **Playwright upstream:** runner, locators, codegen concepts, Trace Viewer, reporters, browser contexts.

## Fork policy
Prefer cherry-picking concepts/components only when license and maintainability are acceptable. Never fork Playwright core. Any third-party code adopted must be recorded with source commit, license, local modifications and upgrade strategy.
